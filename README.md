# Galaxy Photo Shuffle – Galaxy S26+ 完成版プロジェクト

AQUOS「ロック・ホームフォトシャッフル」に近い操作感を、Galaxy S26+向けにしたAndroidアプリのプロジェクトです。

## 対象
- Galaxy S26+
- Android 16系
- One UI 8.5以降を想定
- targetSdk 35

## できること
- ロック画面とホーム画面を個別にON/OFF
- ロック画面用写真を最大15枚
- ホーム画面用写真を最大50枚
- 写真を複数選択
- 直前と同じ写真を避けるランダム選択
- 30分 / 1時間 / 6時間 / 1日
- 今すぐシャッフル
- 再起動後のスケジュール再登録

## Galaxy向けの考え方
Galaxyではロック画面についてSamsung純正の自動切り替え機能も利用できます。
このアプリはAQUOS風に「自分で選んだ写真だけ」を使うことを目的にしています。

ホーム画面はAndroid/Samsungの壁紙仕様上、アプリから1枚ずつ変更する方式です。
One UIの省電力・バックグラウンド制御により、定期実行が遅れる場合があります。

## 使い方
1. Android Studioでこのフォルダを開く
2. Gradle Sync
3. Build > Build APK(s)
4. APKをGalaxy S26+へ転送
5. インストールして「Galaxyフォトシャッフル」を起動
6. 写真を選択
7. ロック画面/ホーム画面をON
8. 間隔を設定
9. 「シャッフルを有効にする」

## 注意
これはSamsung純正アプリではありません。
Samsung/Androidの仕様により、ホーム画面の自動変更やバックグラウンド実行には制限があります。
